# AI Trading Petrunko

**Real-time crypto market intelligence dashboard** — киберпанк-HUD 16:9, где «нейросфера» ищи исторические
аналоги рынка, а живые **бычьи (зелёные) и медвежьи (красные) агенты** визуализируют борьбу сторон
на основе реальных вероятностей модели.

> ⚠️ **Образовательный проект. Не является инвестиционной рекомендацией. Торговля криптовалютой связана
> с высоким риском потери средств.** Прогноз — это вероятность, а не знание будущего.

---

## Быстрый старт

**Windows (рекомендуется):** двойной клик по **`start.bat`** — сам проверит Node, поставит
зависимости (первый запуск), соберёт ядро анализа, поднимёт бэкенд :8787 и фронт :3000
в отдельных свёрнутых окнах и откроет `http://localhost:3000`.

**Вручную (PowerShell с ограниченной политикой выполнения — используй `npm.cmd`):**

```bash
npm.cmd install    # зависимости
npm.cmd run dev     # бэкенд :8787 + Next.js :3000 (и собирает lib/analyze.mjs)
```

Открыть **http://localhost:3000**. Обязательны **оба** процесса: бэкенд (8787) и веб (3000) —
`npm run dev` поднимает их вместе, `start.bat` тоже.

Продакшен-сборка:

```bash
npm.cmd run build   # next build (+ транспиляция ядра анализа)
npm.cmd start       # next start -p 3000 + backend на 8787
```

| Сервис | Порт | Что делает |
|---|---|---|
| Next.js (fr) | 3000 | Дашборд, графики, 3D-сфера |
| Node backend | 8787 | REST `/api/*` + WebSocket `/ws`, прокси бирж, SQLite, worker-потоки анализа |

## Архитектура

```
Браузер (Next.js 14 + TS + Tailwind + Three.js + Lightweight Charts + Framer Motion)
   │  REST /api/*     WS /ws (tick, klines, depth, events, forecast, backtest)
   ▼
Backend (Node, ws, node:sqlite)  ── «мозг» в worker_threads (не блокирует UI)
   │  публичные API, без ключей
   ├── Binance  REST + WS (kline / trade / depth)   ← данные в реальном времени
   ├── Bybit v5 REST + WS (kline / publicTrade / orderbook, funding, OI)
   ├── CoinGecko (глубокая дневная история, ранг монет)
   └── alternative.me (Fear & Greed)
```

* **Binance ↔ Bybit автопереключение**: health-check каждые 20 с, при отказе источника — failover,
  в меню видны `Binance ● / Bybit ●`, латентность и кнопки `BINANCE / BYBIT / АВТО`.
* **CORS/rate-limit**: браузер не ходит в биржи напрямую — всё через прокси-сервер с кешем.
* **Хранение**: SQLite (встроенный `node:sqlite`, без нативных зависимостей): свечи 1m/5m/1h/1d
  с начала листинга (BTC ≈ 81 000 часовых свечей), плюс дневной CoinGecko как запас.
* **TradingView не парсится**: только официальный виджет Advanced Chart (вкладка «Рынки»)
  и open-source Lightweight Charts для собственных графиков — по правилам TradingView.

## «Мозг»: как считается прогноз

1. **Окно** 336 часовых свечей (14 дней) → лог-возвраты («форма кривой», не доллары).
2. **Поиск аналогов по всей истории**: дешёвая косинусная/Пирсон-фильтрация → уточнение **DTW**
   (динамическое выравнивание времени) → топ-50 без пересечения с текущим окном.
3. **Исходы**: для каждого аналога доходность через 1д / 7д / 30д; P(up) — взвешенная доля
   «вверх» (вес = схожесть³, FLAT-зона ±0.5%·√(д/7)).
4. **Ансамбль**: аналоги 50% + техника (RSI/MACD/Bollinger/EMA) 20% + микроструктура
   (дисбаланс стакана, funding, ΔOI) 20% + режим рынка 10%. Панель «Почему такой прогноз» показывает
   веса и голоса каждого компонента.
5. **Расчёт в worker-потоках** (по ТЗ): прогноз каждые ~60 с на монету, walk-forward бэктест — фоном.
6. **Текст-вывод собирается шаблоном только из посчитанных чисел** — ничего не «выдумывается».

### Честность (обязательно прочитать)

* Бэктест — walk-forward за **последние 2 года**: 52 сигнала, горизонт 7 дней, окно 336 свечей.
  Показываются: hit rate по всем сигналам, по «уверенным» (порог 15%), база «всегда вверх»,
  покрытие, калибровка (обещано → сбылось) и кривые «стратегия vs hold».
* **Порог/окно подобраны на валидационной выборке — оценка может быть оптимистичной** (об этом прямо
  написано в панели бэктеста).
* Микроструктуры в истории не существует — её вес в бэктесте честно перераспределён.
* При разногласии аналогов уверенность низкая, ядро сферы тускнеет, зажигается **NO CLEAR EDGE**.

## Дашборд: что на экране (1920×1080, ровно один экран, без скролла)

**Верх:** меню (Дашборд · Рынки · Прогнозы · История · Аналоги · Бэктест · О проекте), часы UTC,
LIVE-пульс, задержка, переключатель источника. Заголовок с дыханием и редким глитчем (8–10 с).
Таблетки монет (топ по капитализации: BTC ETH BNB XRP SOL DOGE ADA AVAX, TON на Binance/Bybit нет —
заменён на AVAX). Бегущая строка ticker внизу.

**Верхний ряд:** PRICE/SPOT (механический roll + вспышка 300 мс, ≥1 тик/с), LIVE CANDLES
(lightweight-charts, 1m/5m/1h/1d, дышащая последняя свеча), ORDER BOOK (горка bid/ask, пульсирующие
стенки, дисбаланс), FEAR & GREED (стрелка + мини-толпа).

**Центр:** NEURAL SPHERE (Three.js: поле точек, 50 точек-аналогов тянутся к полюсам UP/DOWN,
спицы = схожесть, ядро пульсирует 1 Гц и меняет цвет/яркость от вероятности и уверенности,
гироскопические кольца, частицы-всплески от сделок, параллакс мыши, тултип аналога).
**Агенты-команды** поверх сферы (живые):

* 🟢 **BULL-АГЕНТЫ** — зелёные блобы, число ∝ P(UP); 🔴 **BEAR-АГЕНТЫ** — красные, число ∝ P(DOWN);
* **гуляют** по полю (плавные патрульные зоны сверху/снизу), дышат, моргают в разном ритме;
* **смотрят каждый своё**: на собеседника по кабелю, на свой радар, каждый третий — за курсором,
  остальные — в своё направление (эскадрильи смотрят «в разные окна»);
* **кабели связи**: бегущий штрих (team — циан, cross — белый/красный-зелёный узлы) соединяют
  пары агентов, во время разговора кабель становится толще и быстрее;
* **разговор**: у обоих участников включается **небольшой прозрачный купол их цвета**
  (зелёный/красный, стеклянный блик, мягкая подсветка снизу) + реплики-«пузыри» — всегда с
  реальными цифрами прогноза (`P↑ 62% — входим?`, `контр-аналог Sep 2019`, `funding 0.0033%`);
* **анализ**: над головой крутится радар-скоп с лучом и меткой (`⌁ корреляция 67%`);
* всплески трейдов/стенок → команды подпрыгивают; всё уважает ЭКО-РЕЖИМ/prefers-reduced-motion.

Слева метрики-карты (вероятность, уверенность, RSI, MACD, волатильность, funding) со спарклайнами,
справа LIVE FEED (типографский эффект). Низ: ANALOG TIMELINE (клик по месяцу → наложение
«тогда/сейчас/что было дальше», лениво одним запросом), FORECAST FAN (веер траекторий + зоны 50/90%,
шум Перлина), EXECUTION TAPE.

**Вкладки:** Рынки (свечи + официальный TradingView + таблица), Прогнозы (split + веса ансамбля +
ожидания по горизонтам + веер), История (1ч/1д/вся через CoinGecko), Аналоги (топ-50 с исходами),
Бэктест (калибровка, интервалы, equity), О проекте (метод, источники, статус стыка).

**Доступность/производительность:** `prefers-reduced-motion` + кнопка **ЭКО-РЕЖИМ** (выключает
непрерывные анимации глаз/прыжков/веера, ограничивает DPR), requestAnimationFrame, transform/opacity,
WebGL-сфера на GPU, автопереподключение WS с backoff, замер RTT (ping/pong).

**Мобильная:** ≤1024px дашборд перестраивается в вертикальную колонку 9:16.

## API бэкенда

| Endpoint | Описание |
|---|---|
| `GET /api/status` | здоровье источников, статистика, счётчики истории, FNG, ранг |
| `GET /api/candles?symbol=BTC&tf=1h` | свечи из SQLite |
| `GET /api/history?q=1d\|deep` | дневная / глубокая история |
| `GET /api/forecast?symbol=BTC` | прогноз + краткие аналоги |
| `GET /api/analogs?symbol=BTC` / `&at=<ts>` | топ-аналоги / сегменты для наложения (~8 КБ) |
| `GET /api/forecast-fan?symbol=BTC` | квантили, бины, хвост цены для веера |
| `GET /api/backtest?symbol=BTC&full=1` | бэктест + калибровка + серия |
| `GET /api/depth` · `/api/source?s=binance\|bybit\|auto` · `/api/event-log` · `/api/fng` | стакан / источник / лента / F&G |
| `WS /ws` | `sub/unsub/ping` → `hello, klines, m1, depth, depth-lite, tick, health, event, forecast, backtest, fng, rank` |

**Никаких API-ключей в клиентском коде нет и быть не должно.**

## Критерии готовности (сверка с ТЗ)

1. ✅ живая цена BTC обновляется минимум раз в секунду (WS `tick` троттлинг 1 Гц);
2. ✅ сфера вращается (0.05 об/с), реагирует на мышь, показывает UP/DOWN/FLAT с процентами;
3. ✅ поиск аналогов возвращает 50 периодов с датами и схожестью (≥10 по ТЗ);
4. ✅ бэктест показывает точность + калибровку за 2 года;
5. ✅ переключение Binance/Bybit/Auto работает (health + failover);
6. ✅ сетка 16:9 = ровно 1080px без внутреннего скролла (проверено на вьюпорте 1920×1080);
7. ✅ дисклеймер «Не является инвестиционной рекомендацией» — в футере и на вкладке «О проекте».

## Структура репозитория

```
app/                 # Next.js App Router (page, layout, globals.css)
components/          # Shell, Chrome, Panel, FeedPanels, TradingViewWidget
  panels/            # PriceSpot, LiveCandles, OrderBook, FngGauge, MetricCards,
                     # NeuralSphere, Agents, AnalogTimeline, ForecastFan, ExecutionTape
  views/             # Markets, Forecast, History, Analogs, Backtest, About
lib/                 # analyze.ts (единое ядро: индикаторы, DTW-поиск, ансамбль, бэктест),
                     # store.tsx (WS/REST-состояние), api.ts, types.ts, format.ts
components/          # Shell, Chrome, Panel, Style (hydration-safe CSS), FeedPanels, TradingViewWidget
server/              # index.mjs (HTTP+WS хаб), exchange.mjs, history.mjs, store.mjs,
                     # analysis.mjs (пул worker_threads), worker.mjs
tools/               # build-core.mjs (TS→ESM для сервера), debug-скрипты методологии
data/                # SQLite (создаётся при первом запуске, в git не попадает)
start.bat            # Windows: install → core build → backend :8787 → frontend :3000
```

`lib/analyze.ts` — **единственный источник правды**: Next компилирует его как TS, сервер получает
тот же файл в `lib/analyze.mjs` (генерируется `tools/build-core.mjs` при `predev`/`build`).
Логика фронта и бэка не расходится.
