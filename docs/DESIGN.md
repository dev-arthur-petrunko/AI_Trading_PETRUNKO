# ДИЗАЙН И СТИЛЬ — «AI Trading Petrunko»

Полное описание визуальной системы проекта: цвета, типографика, масштаб, эффекты,
компоновка экранов и что в каком окне отображается. Значения взяты из реального кода
(`app/globals.css`, `components/Shell.tsx`, `components/Panel.tsx`, `components/Chrome.tsx`,
`components/panels/*`, `components/views/*`).

## 1. Цветовая система

### 1.1 Токены (`app/globals.css` → `:root`)

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#050a12` | фон всего приложения (почти чёрный с синим) |
| `--panel` | `rgba(8, 16, 30, 0.55)` | фон панели — **полупрозрачный** (см. §4.2) |
| `--stroke` | `#1b3a5c` | рамки, разделители, границы («сталь») |
| `--bull` | `#19f58a` | **быки / рост / покупка** — зелёный |
| `--bear` | `#ff3b5c` | **медведи / падение / продажа** — красный |
| `--cyan` | `#2dd4ff` | акцент HUD: уголки, активные элементы, «нейтраль» |
| `--amber` | `#ffb020` | предупреждение, флэт, «нет явного края», страхи |
| `--ink` | `#d8e6f5` | основной светлый текст |
| `--dim` | `#6f8aa8` | приглушённый/подписной текст |

JS-дубликат для инлайновых стилей — `lib/format.ts` → `COLORS` (те же значения + `stroke`).

Дополнительные оттенки (точечные):
- `#FF7A45` — переход «страх» (FNG 25–45);
- `#9BE85B` — переход «жадность» (FNG 55–75);
- `#03130b` — **тёмный текст на насыщенной подложке**: активная пилюля/вкладка/чип
  (тёмно-зелёный/тёмно-циановый бэкграунд + такой текст).

### 1.2 Семантика цвета (единая во всём интерфейсе)

- **Зелёный** — только «вверх/покупка/быки»: P↑, BUY, bid-стороны стакана, рост 24ч, купол быков.
- **Красный** — только «вниз/продажа/медведи»: P↓, SELL, ask-стороны, падение, купол медведей.
- **Циан** — нейтраль/акцент системы: заголовки иконок, уголки панелей, active-состояния,
  медиана, «системные» события ленты, сканеры.
- **Янтарь** — «внимание/сомнение»: NO CLEAR EDGE, киты (WHL), стенки, волатильность,
  дисклеймер-акценты, базовая линия.
- **ink/dim** — контент/подписи соответственно.

## 3. Масштабирование и адаптив

### 3.1 Базовый принцип — «1 design-pixel» `--u`

```css
--u: calc(min(100vw, 177.78vh) / 1920);
```

Всё в интерфейсе измеряется в `u` (1/1920 эталонной ширины при 16:9). Приложение живёт
внутри «сцены» `.stage` с жёстким `aspect-ratio: 16/9` (`width: min(100vw, 100vh·16/9)`),
поэтому на любом мониторе пропорции окон не едут.

### 3.2 Медиазапросы

| Блок | Условие | Что меняется |
|---|---|---|
| Планшет/малый десктоп | `max-width: 1024px` | `--u: calc(100vw / 430)` (масштаб от ширины «телефона»); `.stage` → `width:100vw; aspect-ratio:auto; min-height:100vh`; **сетка дашборда → flex-колонка** (шар первой, `order:-1`, `min-height:460u`); панели `min-height:240u` (fng/feed/tape — `200u`); `padding` контента 8u; футер переносится |
| Малые телефоны | `max-width: 560px` | `--u: calc(100vw / 400)`; TopBar переносится в 2 строки, **навигация — отдельной строкой вниз шапки, горизонтальный скролл без полосы**, бренд-название скрыто (остаётся логотип); заголовок главы 24u, подпись скрыта; пилюли и кнопки ужаты; у футера дисклеймер на всю строку |
| Короткий альбомный экран (телефон поперёк) | `max-height: 540px` + `orientation: landscape` + `min-width: 640px` | `--u: calc(100vh / 300)`; заголовок главы 34u, подпись скрыта; TopBar без `min-height`; ряды сетки дашборда жёстко `150u / 1fr / 165u` |
| Уменьшенная анимация | `prefers-reduced-motion: reduce` | всем анимациям `duration .001s !important`, `iteration-count 1`, переходы `.1s` |

### 3.3 Мобильная колонка дашборда (≤1024px)

Порядок сверху вниз: **Neural Sphere (первая, крупная) → Price → Candles → Order Book →
F&G → AI Metrics → Feed → Fan → Timeline → Tape**.

### 4.2 Панель `.panel` (окно HUD) — скруглённое и полупрозрачное

```css
.panel {
  background: rgba(8, 16, 30, 0.55);              /* полупрозрачное стекло */
  border: 1px solid var(--stroke);                 /* тонкая стальная рамка */
  border-radius: calc(var(--u) * 18);              /* СКРУГЛЕНИЕ углов (~38px на 1920) */
  backdrop-filter: blur(14px) saturate(1.15);      /* сквозное размытие фона с подсветкой цвета */
  display: flex; flex-direction: column;
  overflow: hidden;
}
```

- **Уголки HUD**: 4 спана `.panel-corner tl/tr/bl/br`, каждый `10u×10u`, рисуют
  **L-образные уголки** `border-сторона: 2px solid var(--cyan)`. Позиционированы
  **внутрь радиуса** (`top/left: 13u`), чтобы не ломать скруглённый силуэт.
- **Редкое свечение рамки**: псевдоэлемент `.panel::after` (`inset:-1px`,
  `border-radius: inherit`), анимация `frameGleam 7s` c задержкой `--gleam-delay`
  (у каждой панели своя, чтобы вспышки не совпадали): 95% цикла — рамка вспыхивает
  цианом `rgba(45,212,255,.55)` + внутренняя тень.
- **Шапка `.panel-head`**: моно, `fs-xs`, `letter-spacing .14em`, uppercase, цвет dim;
  слева иконка (`.ico`, циан) + заголовок, справа — `right`-слот и мигающая точка `.dot`
  (`6u`, циан, `box-shadow` + анимация `dotBlink 2.4s`: 1 ↔ .35).
- **Тело `.panel-body`**: `flex:1; padding:10u; overflow:hidden`. Модификатор `.flush`
  убирает отступ (графики/таблицы впритык).
- **Появление `.panel-in`**: анимация `panelIn .55s` — раскрытие из горизонтальной щели
  (`clip-path: inset(50% 0) → 0`) + вспышка `brightness(3) saturate(0) → none`;
  задержка = проп `delay` (панели появляются каскадом слева-направо, сверху-вниз).

## 7. Neural Sphere — главное окно

### 7.1 Состав 3D-сцены (Three.js, `components/panels/NeuralSphere.tsx`)

`WebGLRenderer({alpha:true})`, камера `PerspectiveCamera(45°)`, группа параллакса (наклон
за курсором, сглаживание .05) внутри — группа вращения **0.05 об/с**.

1. **Каркас-шар (главный рисунок)** — «плетение» из точек и нитей:
   - **N=4600 точек** (в ЭКО — 1500) по золотому спиралу (равномерно на сфере, ±радиус);
   - **нити** как индексы LineSegments: сосед по спирали `i→i+1` (плотная обмотка),
     хорда `i→i+41` каждая 4-я точка (средние связи) и `i→i+233` каждая 47-я (длинные,
     редкие — дают «свитый клубок», не сливаясь в кашу);
   - **цвет по широте без белого**: `t = (y+1)/2` (0 — низ, 1 — верх), полярность
     `|t−0.5|·2` (0 на экваторе → 1 у полюсов), интенсивность `0.5 + 0.6·полярность`
     × случайный `0.68…1.0`; каналы: `R = 1.0→0.17`, `G = 0.55→0.83`, `B = 0.12→1.0`
     — то есть **снизу тёплый янтарь, сверху холодный циан, экватор — приглушённый**;
   - **`NormalBlending`** (не аддитив!) — наложенные нити не суммируются в сплошное
     белое пятно; `depthWrite:false`, `vertexColors:true`;
   - прозрачности: нити **0.7**, точки **0.85** (в интро — от 0 к этим значениям за 1.4 с,
     вместе со сборкой `scale 0.06→1`);
   - точки: `PointsMaterial size 0.016` (ЭКО 0.022) с радиальной glow-текстурой.
2. **Ядро** — сфера `0.17` + голо-спрайт (`scale 0.7`):
   - пульс ~1 Гц (`coreBeat`);
   - цвет доезжает лерпом: **зелёный** — явный перевес вверх, **красный** — вниз,
     **янтарь** — прогноза нет / NO CLEAR EDGE;
   - яркость от уверенности: `glowTarget = 0.35 + conf·0.5`, `opacity = 0.25 + conf·0.5`.
3. **Три кольца-гимбалы** (тора R 1.30/1.44/1.58, контр-вращение +0.22/−0.16/+0.10 рад/с,
   циан, opacity .32) с насечками (48 и 24 риски, каждая 6-я длиннее; в ЭКО без рисок).
4. **Точки-аналоги (до 50)** — золотое сечение + **подтяжка к полюсу результата**:
   `y += 0.5` (up) / `−0.5` (down). Цвет: **зелёный = вырос, красный = упал, циан = флэт**;
   яркость `0.55 + sim·0.45` (**чем больше похожесть, тем ярче**), size .055.
5. **Спицы** от ядра к каждой точке: яркость по схожести (`0.12 + sim·0.55`), opacity .5.
6. **Хорды** (до 18) между ближайшими по времени аналогами одного знака — «сетка схожести».
7. **Частицы-burst** (36, в ЭКО 0): вылетают из центра и влетают в ядро за 1.1 с;
   триггеры — сделки/киты в ленте и приход пакета от агента (`aps-packet`).

### 7.2 HTML-оверлей окна

- **Полюса** (Orbitron): `UP` сверху с `P↑` (зелёный+свечение), `DOWN` снизу с `P↓`
  (красный+свечение), `FLAT` справа внизу (dim, мелкий);
- **`NO CLEAR EDGE`** — янтарь справа сверху, мигает `dotBlink 1.6s`, только если нет
  явного перевеса;
- **бейдж «ПРИЁМ · ядро → AI Metrics»** (`.recv-badge`, циан, z-8): вспыхивает цветом
  агента на 1400 мс при приходе пакета;
- **тултип** при наведении на точку-аналог (raycast): период / схожесть / результат через
  горизонт (цвет по знаку);
- **текст прогноза** внизу — на градиентной подложке `transparent → rgba(5,10,18,.85) → transparent`.

### 7.3 Поток «шар → AI Metrics»

Каждые 8 с (и при публикации) ядро шлёт событие `aps-out` `{label, probUp, confidence,…}`:
1. `MetricCards` ловит: карточки вспыхивают каскадом (`cardLit .25s` задержек) и
   появляется плашка **«◄ ИЗ ЯДРА: P↑ …% · conf …%»** (`coreChip 3.4s`);
2. `Agents` ловит: от прямоугольника сферы в прямоугольник AI Metrics **летит пакет**
   (`pkFly 1.1s`) с подписью показания.

### 7.4 Агенты (`components/panels/Agents.tsx`)

- **До 10 агентов**: количество быков/медведей пропорционально P↑/P↓ (по 2–5 каждых);
- **тело** — эллипс с бликом, **зелёный = бык, красный = медведь**, глаза следят и моргают
  (`ag-blink 3.2–5.3с`), тело дышит (`ag-breathe 2.9s`), прыжок на сделки своей стороны
  (`ag-hop .65s`);
- **патруль по всем 10 панелям**: move 1750мс → scan 2300мс → rest; во время скана —
  **радар** (3 кольца + вращающийся луч `radar-spin 1.1s` + blip) и подпись «⌁ PRICE SCAN / CORE SYNC…»;
- **диалог**: облачко речи (рамка цвета стороны, `speech-in .28s`, живёт 3.6с) — текст из
  **реальных показаний той панели, где агент стоит**; над говорящим — **полупрозрачный
  купол его цвета** (`border-radius: 50% 50% 18% 18% / 82% 82% 10% 10%`, `dome-in .3s` +
  `dome-pulse 1.6s`);
- **мысли** — облачко cyan с числами (`ag-think 1.9s`): «P↑ 62% / аналог 84% / Δ7д +1.2%»;
- **кабели** — пунктирные дуги с бегущим штрихом (`cable-run .85s`): свои-свои циан,
  бык↔медведь — светлый, «разговор» — яркий циан; узлы пульсируют;
- **пакеты в ядро**: полоса + точка летит к центру сферы, подпись показания поднимается
  и гаснет (`pkLabel 1.15s`); через 560 мс сфера отвечает событием → счётчик ПРИЁМ + burst;
- **флажки у сферы**: слева сверху `BULL-АГЕНТЫ ▲ N% [N]` (зелёные), справа снизу
  `BEAR-АГЕНТЫ ▼ N% [N]` (красные);
- в ЭКО — статичная раскладка 2×5, анимации выключены.

## 8. Графики: за что каждый отвечает (дизайн)

### 9.5 Бэктест
Одно большое окно: ряд **KPI ×4** (ТОЧНОСТЬ / «ВСЕГДА ВВЕРХ» / ТОЛЬКО УВЕРЕННЫЕ /
ГОРИЗОНТ — крупное значение + подпись + строка пояснения «vs база +N п.п.»), затем блок
**ТОЧНОСТЬ ПО МЕСЯЦАМ** (столбцы vs янтарная база), блок **СРАВНЕНИЕ ПО ВСЕМ МОНЕТАМ**

## 11. Чек-лист стиля (кратко)

1. Всё измеряется в `u` (1/1920 эталона); экран живёт в 16:9-сцене.
2. Окна — **полупрозрачные со скруглением 18u** и сквозным `blur(14px) saturate(1.15)`.
3. У каждого окна: HUD-уголки цианом (внутри радиуса), шапка моно-uppercase, мигающая
   точка, редкая вспышка рамки, каскадное появление.
4. Цвет только по семантике: зелёный↑ / красный↓ / циан-система / янтарь-внимание.
5. Цифры всегда моноширинные (JetBrains Mono, tabular-nums).
6. Адаптив: ≤1024 — колонка со шаром первой; ≤560 — двухстрочный TopBar с навигацией
   в отдельной строке; короткий альбомный — сжатая сетка.
7. ЭКО-режим и `prefers-reduced-motion` выключают тяжёлые анимации.
